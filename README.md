# ADI — Machine Learning Analysis

Academic project developed for the Intelligent Learning and Decision Making
course at the University of Minho during the 2025/2026 academic year.

## Overview

This project explores the complete data analysis and machine learning
workflow using KNIME, from data exploration and preprocessing to model
development and evaluation.

Two machine learning problems were addressed:

- **Regression:** predicting taxi trip prices based on trip and pricing
  characteristics.
- **Classification:** predicting energy production levels using weather,
  temporal, and solar radiation-related attributes.

The project also includes data cleaning, missing value treatment,
outlier handling, feature selection, and model comparison.

## Models

### Regression

Several regression models were developed and compared, including:

- Linear Regression
- Regression Tree
- Gradient Boosted Trees
- Random Forest
- Neural Networks

### Classification

Classification and clustering approaches were also developed for the
energy production dataset.
